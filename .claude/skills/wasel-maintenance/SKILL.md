# الصيانة الدورية — منصة واصل

اسأل أولًا (أو استنتج من الطلب): **يومية / أسبوعية / شهرية؟**
القائمة الكاملة في `docs/ops/04-maintenance.md` — اتبعها بندًا بندًا ولا تتجاوز أي بند بصمت.

## يومية

```bash
bash ops/health-check.sh
```
\+ نظرة على اللوحة: Dashboard يفتح، عدد Hotspot Active منطقي، تقرير اليوم فيه حركة.

## أسبوعية

```bash
bash ops/backup.sh
df -h
tail -100 /var/log/nginx/error.log 2>/dev/null
```
ثم:
- [ ] **انقل النسخة خارج السيرفر** (نسخة على نفس السيرفر ليست نسخة احتياطية)
- [ ] نسخة الراوتر: `/system backup save name=wasel-weekly` و `/export file=wasel-config`
- [ ] نظّف المستخدمين المنتهين من اللوحة (User List ← فلتر expired)
- [ ] راجع `docs/ops/05-renewals.md`: أي شيء خلال 30 يوم؟

## شهرية

- [ ] تحديثات أمنية للنظام — **في نافذة الصيانة فقط، وبإذن**
- [ ] مراجعة جلسات الراوترات الميتة في `include/config.php`
- [ ] مراجعة مستخدمي الراوتر (`/user print`) وتعطيل غير المستخدم
- [ ] **اختبار استرجاع فعلي** في بيئة docker (مش الإنتاج)
- [ ] تحديث `docs/ops/02-inventory.md` لو أي شيء اتغيّر
- [ ] مراجعة قائمة `docs/ops/07-security.md`

## قواعد ملزمة

1. أي عمل يقطع الخدمة → نافذة الصيانة المتفق عليها فقط + إذن المالك.
2. نسخة احتياطية قبل أي تغيير.
3. تغيير واحد في المرة.
4. بعد الانتهاء: `bash ops/health-check.sh` ثم **سجّل صفًا في جدول سجل الصيانة**
   في نهاية `docs/ops/04-maintenance.md`.

## التقرير

```
نوع الصيانة: ...

حالة النسخ الاحتياطي: (السيرفر / الراوتر / خارج السيرفر)
مطلوب منك: ...
```
