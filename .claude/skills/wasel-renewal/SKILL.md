# التجديدات — منصة واصل

## 1. فحص آلي للتواريخ

```bash
bash ops/health-check.sh          # يفحص SSL تلقائيًا لو WASEL_DOMAIN مضبوط

# الدومين
whois <DOMAIN> | grep -iE "expiry|expiration"

# الشهادة (يدويًا)
echo | openssl s_client -servername <DOMAIN> -connect <DOMAIN>:443 2>/dev/null \
  | openssl x509 -noout -enddate
```

## 2. طابِق مع الجدول

افتح `docs/ops/05-renewals.md` وحدّث كل تاريخ فعلي تحقّقت منه.
أي بند فيه `؟؟؟` → **اسأل المالك، لا تخمّن**.

عتبات الإنذار:
| البند | ينبّه قبل |
|---|---|
| الدومين | 60 يوم |
| الاستضافة/VPS | 30 يوم |
| شهادة SSL | 21 يوم |
| اشتراك المزوّد | 14 يوم |

## 3. التنفيذ

**شهادة Let's Encrypt:**
```bash
certbot renew --dry-run       # تجربة أولًا
certbot renew
systemctl reload nginx
systemctl enable --now certbot.timer    # لو التجديد التلقائي معطّل
```

**الدومين / الاستضافة:** تجديد مالي — يُنفّذه المالك. مهمتك التنبيه المبكر
بالتاريخ والتكلفة والمزوّد، وتأكيد التجديد بعده.

**تجديد باقة زبون (داخل اللوحة):**
- تاريخ الانتهاء في حقل `comment` للمستخدم داخل الراوتر.
- التجديد = Reset للمستخدم أو كرت جديد بنفس البروفايل.
- ⛔ لا تعدّل حقل `comment` يدويًا لو كان بصيغة التاريخ — يكسر حساب الانتهاء.

## 4. التوثيق

- حدّث جدول التجديدات + سجل التجديدات المنفّذة في `docs/ops/05-renewals.md`.
- لو تغيّر مزوّد أو حساب → حدّث `docs/ops/02-inventory.md`.
