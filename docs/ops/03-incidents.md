# 03 — كتيّب الأعطال (Runbook)

## التصنيف والاستجابة

| المستوى | الوصف | الاستجابة | هل يحتاج إذن؟ |
|---|---|---|---|
| **P1** | الزبائن ما قادرين يتصلوا بالإنترنت | فورًا | لا — أصلح ووثّق |
| **P2** | اللوحة واقفة، لكن الإنترنت شغال | خلال ساعة | لا |
| **P3** | ميزة واحدة معطلة (تقرير، طباعة، توليد كروت) | نفس اليوم | لا |
| **P4** | بطء، تحسينات، أخطاء تجميلية | حسب الأولوية | نعم قبل النشر |

**دايمًا قبل أي إصلاح:** `bash ops/backup.sh` — إلا لو السيرفر نفسه ما شغال.

---

## القاعدة الذهبية في التشخيص

اللوحة (Mikhmon) **ليست** مزوّد الخدمة. الإنترنت بيمشي عبر الراوتر لوحده.
لذلك أول سؤال دائمًا:

```
الزبائن ما عندهم إنترنت؟  → المشكلة في الراوتر أو المزوّد، مش في اللوحة
اللوحة ما بتفتح/ما بتتصل؟ → المشكلة في السيرفر أو مسار الشبكة، والزبائن غالبًا بخير
```

---

## 1. الصفحة بيضاء / فارغة تمامًا

السبب شبه المؤكد: خطأ PHP مكتوم بسبب `error_reporting(0)` الموجود في كل ملف.

```bash
# 1) اقرأ السجل الحقيقي
tail -50 /var/log/nginx/error.log
tail -50 /var/log/php*-fpm.log

# 2) لو السجل فاضي، فعّل الأخطاء مؤقتًا (على ملف واحد فقط، ورجّعه بعدها)
php -l <الملف المشتبه به>
```
الأسباب الشائعة: ملف مفقود (راجع
[01-architecture.md §7](01-architecture.md#7-ملفات-ناقصة-في-هذا-الـ-fork-مؤكدة))،
أو `include/config.php` اتخرب، أو صلاحيات ملفات.

## 2. "Mikhmon not connected" عند اختيار الراوتر

الترتيب الصحيح للفحص:

```bash
# أ) هل منفذ API مفتوح أصلاً؟
nc -vz <ROUTER_IP> 8728        # أو  bash ops/health-check.sh

# ب) من داخل الراوتر (Winbox/SSH):
#    /ip service print          → لازم api يكون enabled
#    /ip service set api disabled=no
#    /user print                → تأكد المستخدم موجود وفعّال وله صلاحية api
```

| السبب | الإصلاح |
|---|---|
| خدمة `api` مقفولة في الراوتر | `/ip service set api disabled=no` |
| كلمة مرور الراوتر اتغيّرت | أعد إدخالها من Session Settings في اللوحة |
| الراوتر خلف VPN والـ VPN فصل | أعد رفع الـ VPN ثم جرّب |
| `address` list على خدمة api يمنع IP السيرفر | أضف IP السيرفر في `/ip service set api address=` |
| منفذ غير افتراضي | اكتب `IP:PORT` في حقل IP بالإعدادات |
| firewall على السيرفر | افحص egress على 8728 |

## 3. الزبائن ما قادرين يسجلوا دخول للهوت سبوت (P1)

اللوحة غالبًا بريئة. افحص بالترتيب:

1. **هل الراوتر شغال أصلاً؟** ping للراوتر.
2. **هل خط المزوّد (WAN) شغال؟** من الراوتر: `/ping 8.8.8.8`.
3. **هل سيرفر الهوت سبوت فعّال؟** `/ip hotspot print` → ما يكون `invalid`.
4. **هل المستخدم منتهي؟** اللوحة ← User List ← عمود `comment` فيه تاريخ الانتهاء.
5. **هل امتلأ عدد المستخدمين المسموح في الترخيص؟** `/system license print`.
6. **هل `/system scheduler` حذف المستخدمين بالغلط؟** راجع سكربت البروفايل.

> ⚠️ لا تعيد تشغيل الراوتر كحل أول. إعادة التشغيل تقطع كل الزبائن
> وتخفي السبب الحقيقي. لا تُستخدم إلا بإذن صريح من المالك.

## 4. التقارير اختفت أو صفر

التقارير مخزّنة **داخل الراوتر** كـ `/system/script`. تختفي لو:

- تنفّذ `process/removereport.php` (زر حذف التقرير) — **لا رجعة**، إلا من نسخة الراوتر.
- سكربت `on-login` في البروفايل ما اتحدّث (بعد أي ترقية للوحة لازم تفتح كل
  user profile وتضغط Save عشان يتجدد السكربت).
- المستخدم سجّل دخول **قبل** تحديث البروفايل → بيفضل على النظام القديم.

الفحص:
```
# من الراوتر
/system script print where name~"mikhmon"
```

## 5. الكروت (Vouchers) ما بتطبع صح

| العَرَض | السبب | الإصلاح |
|---|---|---|
| صفحة الطباعة فاضية | قالب مفقود في `voucher/` | ارجع للقالب الافتراضي من محرر الكروت |
| QR ما بيظهر | القالب لسه على الصيغة القديمة `<img src="<?= $qrcode ?>">` | الصيغة الجديدة: `<?= $qrcode ?>` بدون وسم img |
| السعر غلط/فاضي | حقل selling price فاضي في البروفايل | عدّل البروفايل وأعد الحفظ |

## 6. اللوحة بطيئة جدًا

كل تحميل صفحة يفتح اتصال TCP جديد بالراوتر (سقف 5 ثوانٍ). البطء يعني غالبًا:
- الراوتر بعيد أو خلف VPN بطيء → قلّل `auto reload` في الإعدادات (الحد الأدنى 10 ثوانٍ).
- `Live Report` مفعّل → يعمل polling مستمر. عطّله من إعدادات الجلسة عند الحاجة.
- الراوتر نفسه محمّل CPU → `/system resource print`.

## 7. لا أستطيع الدخول للوحة

1. تأكد من `include/config.php` — سطر `$data['mikhmon']` موجود وسليم.
2. لو كلمة المرور ضاعت: تُولَّد قيمة جديدة بنفس دالة `encrypt()`:
   ```bash
   php -r 'function encrypt($s,$k=128){$r="";for($i=0,$n=strlen($s);$i<$n;$i++){$c=substr($s,$i,1);$kc=substr($k,($i%strlen($k))-1,1);$r.=chr(ord($c)+ord($kc));}echo base64_encode($r),"\n";}encrypt("كلمة_المرور_الجديدة");'
   ```
   ثم ضع الناتج بعد `mikhmon>|>` في `include/config.php`.
3. جلسة PHP عالقة → امسح كوكيز المتصفح أو أعد تشغيل php-fpm.
