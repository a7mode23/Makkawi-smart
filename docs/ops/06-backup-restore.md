# 06 — النسخ الاحتياطي والاسترجاع

## قاعدة أساسية: عندك مصدرَي بيانات، مش واحد

| المصدر | يحتوي | لو ضاع |
|---|---|---|
| **السيرفر** (ملفات المنصة) | إعدادات الراوترات، الأدمن، قوالب الكروت، الشعار | تعيد الإعداد خلال ساعة |
| **الراوتر** (MikroTik) | المستخدمون، البروفايلات، **كل تقارير المبيعات** | ⚠️ خسارة نهائية |

**نسخة السيرفر وحدها لا تكفي.** لازم نسخة الراوتر كمان.

---

## أ) نسخ السيرفر

```bash
bash ops/backup.sh                       # ينسخ إلى ./backups افتراضيًا
WASEL_BACKUP_DIR=/var/backups/wasel bash ops/backup.sh
```

يشمل: `include/config.php`, `include/lang.php`, `include/theme.php`,
`voucher/template*.php`, `img/`, ومعه بصمة SHA256 وملف بيانات وصفية.

**جدولته (cron يومي 3 فجرًا):**
```cron
0 3 * * * cd /var/www/wasel && WASEL_BACKUP_DIR=/var/backups/wasel bash ops/backup.sh >> /var/log/wasel-backup.log 2>&1
```

> النسخة على نفس السيرفر ليست نسخة احتياطية. انقلها خارجه
> (`rsync`/`rclone`/تخزين سحابي) وإلا فقدان السيرفر = فقدان كل شيء.

## ب) نسخ الراوتر (MikroTik)

```
/system backup save name=wasel-$(date)      # نسخة ثنائية كاملة (لنفس الجهاز)
/export file=wasel-config                   # نسخة نصية (قابلة للقراءة والنقل لجهاز آخر)
```
ثم نزّل `wasel-*.backup` و `wasel-config.rsc` من `Files` واحفظهم مع نسخة السيرفر.

الفرق المهم:
- `.backup` = نسخة كاملة **لنفس الجهاز ونفس الإصدار** (تشمل كلمات المرور).
- `.rsc` = نص الأوامر، يشتغل على جهاز آخر، **لكن لا يشمل كلمات مرور المستخدمين**.

خذ **الاثنين**.

## ج) الاسترجاع

### استرجاع ملفات المنصة
```bash
bash ops/restore.sh backups/wasel-backup-YYYYmmdd-HHMMSS.tar.gz
```
السكربت يأخذ نسخة أمان من الوضع الحالي قبل الكتابة فوقه، ويطلب تأكيد صريح.

بعد الاسترجاع:
```bash
bash ops/health-check.sh
```
ثم افتح اللوحة وتأكد: الدخول يشتغل، الراوترات ظاهرة، الاتصال ينجح.

### استرجاع الراوتر
```
/system backup load name=wasel-weekly     # يعيد التشغيل تلقائيًا
# أو للنسخة النصية:
/import file-name=wasel-config.rsc
```

## د) اختبار الاسترجاع (شهريًا — غير قابل للتأجيل)

نسخة ما اتجرّبت = نسخة ما موجودة.

```bash
# في بيئة معزولة، مش الإنتاج
git clone <repo> /tmp/wasel-test && cd /tmp/wasel-test
bash ops/restore.sh /var/backups/wasel/wasel-backup-<latest>.tar.gz
docker compose up -d      # افتح http://localhost:8080 وتأكد من الدخول
```
سجّل النتيجة في [04-maintenance.md](04-maintenance.md).

## هـ) سياسة الاحتفاظ

| النوع | التكرار | المدة | المكان |
|---|---|---|---|
| ملفات السيرفر | يومي | 14 يوم | محلي + خارجي |
| ملفات السيرفر | أسبوعي | 8 أسابيع | خارجي |
| نسخة الراوتر | أسبوعي | 8 أسابيع | خارجي |
| نسخة الراوتر | قبل أي ترقية | للأبد | خارجي |

## و) ⚠️ تحذير أمني حول النسخ

`include/config.php` يحتوي كلمات مرور الراوترات بتشفير ضعيف قابل للفك
(راجع [07-security.md](07-security.md)).
لذلك **ملف النسخة الاحتياطية = ملف أسرار**:
- لا يُرفع إلى GitHub ولا إلى تخزين عام أبدًا.
- صلاحياته `600` والمجلد `700`.
- لو خُزّن سحابيًا → مشفّرًا (`gpg -c` أو تشفير من جهة المزوّد).
