أي معلومة عن السيرفر أو المنصة أو أي عطل حصل مرة واحدة → مكانها هنا، لأن الإيجنت
يقرأ من هنا قبل ما يتصرف في أي شيء.

## المبدأ الأساسي

المنصة دي **تشغيل حي** — فيها زبائن متصلين وفيها فلوس (كروت/فواتير).
لذلك القاعدة: **نسخة احتياطية قبل أي تغيير، وتغيير واحد في المرة، وتوثيق بعده مباشرة.**

## الملفات القابلة للتنفيذ

| السكربت | الوظيفة |
|---|---|
| `ops/health-check.sh` | فحص صحة شامل (المنصة + السيرفر + الراوتر + SSL + النسخ) |
| `ops/backup.sh` | نسخة احتياطية من كل ملفات الحالة (state) |
| `ops/restore.sh` | استرجاع نسخة احتياطية |
| `ops/inventory.example.env` | قالب متغيّرات البيئة للسكربتات |

## طريقة استدعاء الإيجنت

```
@wasel-ops المنصة واقفة، الزبائن ما قادرين يدخلوا
@wasel-ops سوّي الصيانة الأسبوعية
@wasel-ops شوف شنو بينتهي الشهر الجاي
```

أو عن طريق الأوامر الجاهزة:

```
/wasel-health        فحص شامل
/wasel-incident      استجابة عطل
/wasel-maintenance   صيانة دورية
/wasel-renewal       مراجعة التجديدات
```
