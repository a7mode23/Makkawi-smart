## فحص آلي للتواريخ

```bash
# انتهاء شهادة SSL
echo | openssl s_client -servername <DOMAIN> -connect <DOMAIN>:443 2>/dev/null \
  | openssl x509 -noout -enddate

# انتهاء الدومين
whois <DOMAIN> | grep -iE "expiry|expiration"
```
كلاهما مدمج أصلاً في `ops/health-check.sh` لو ضبطت `WASEL_DOMAIN`.

## تجديد شهادة Let's Encrypt

```bash
certbot renew --dry-run      # تجربة بدون تنفيذ
certbot renew                # التنفيذ الفعلي
systemctl reload nginx       # إعادة تحميل بدون قطع
```
لو التجديد التلقائي معطّل، فعّله:
```bash
systemctl enable --now certbot.timer
systemctl list-timers | grep certbot
```

## تجديد باقات الزبائن (داخل المنصة)

هذا نوع مختلف من "التجديد" — تجديد كرت/اشتراك زبون:

1. **كرت منتهي**: تاريخ الانتهاء موجود في حقل `comment` للمستخدم في الراوتر.
2. **التجديد** = إعادة تعيين المستخدم (Reset) أو إنشاء كرت جديد بنفس البروفايل.
3. **مهم:** لا تعدّل حقل `comment` يدويًا لو كان بصيغة التاريخ
   (`mar/20/2019 16:05:11`) — النظام يعتمد عليه لحساب الانتهاء.
4. تنظيف المنتهين: من User List ← الضغط على `expired` في عمود comment.
